📝 Repositório de Exercícios JavaScript

Bem-vindo ao seu repositório de exercícios de JavaScript, focado na progressão do básico ao avançado! Este projeto é estruturado para fornecer uma experiência de aprendizado prática, utilizando ferramentas modernas como TypeScript, e explorando ambientes de desenvolvimento versáteis, como a entrada/saída via readline-sync para exercícios de console e a arquitetura NestJS para conceitos mais avançados de backend.
